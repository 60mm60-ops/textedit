# 原稿エディタ（ローカル保存版）

小説・漫画シナリオ執筆用のReact + Viteアプリです。

## 機能
- 作品内の章の追加・切替・削除
- リアルタイム文字数カウント（空白・改行の計上切替）
- `「...」` 内のセリフ抽出。出力時はカッコを除去し、セリフ内改行は維持
- セリフの個別コピー・一括コピー、本文/セリフTXT出力
- IndexedDBによる端末内自動保存
- JSONバックアップのエクスポート/インポート
- スマホ・PC対応

## 開発

```bash
npm install
npm run dev
```

## GitHub → Vercel

1. このフォルダの内容をGitHubリポジトリのルートにpushします。
2. Vercelで **Add New → Project** からリポジトリをImportします。
3. Framework Preset: **Vite**、Build Command: `npm run build`、Output Directory: `dist` でデプロイします。

## 重要な制限

**この版は端末間同期に未対応です。** Vercelはアプリ配信のみを行い、原稿は各端末のIndexedDBに保存します。ブラウザデータの削除・プライベートブラウズ・端末故障で原稿が失われる可能性があるため、JSONバックアップを定期的に書き出してください。複数端末で同時に編集しても統合されません。

将来の非同期同期には、クライアント側暗号化・端末ペアリング・一時配送領域・競合処理・受信確認後削除・失効期限などが必要です。同期機能が実装済みであるかのように案内しないでください。

セリフ抽出は単純な `「...」` の組み合わせを対象とします。入れ子のカッコや未閉じのカッコには対応していません。

## 保存の改善
- 入力ごとに復旧用データをlocalStorageへ保存し、IndexedDBにも順番に保存します。
- 再読み込み時は復旧用データを優先します。保存完了表示はIndexedDBの処理完了後です。
- 読み込みエラーでは初期原稿による上書きを停止します。
- 保存できない場合は警告を表示し、画面上の原稿をJSONバックアップできます。
- 別タブによる保存内容の変更を検出した場合は上書きを止めます。ただし完全な同時編集制御ではありません。編集は1タブで行ってください。

localStorageとIndexedDBの両方に原稿を置くため、空き容量に余裕が必要です。ブラウザ終了や端末障害に対する完全な保証はありません。従来どおりJSONバックアップも保管してください。
